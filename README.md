# Blood Organization System

## About the Project

The **Blood Organization System** is a Java-based application developed to manage blood donors and recipient requests. It helps organize donor information, handle blood requests, and maintain donation records using a MySQL database.

The main objective of this project is to make blood donor and recipient information easier to manage.

## Features

- **Donor Registration:** Register and maintain blood donor details.
- **Blood Requests:** Manage blood requests from recipients.
- **Donation Records:** Store and maintain blood donation records.
- **Database Management:** Store and retrieve information using MySQL.

## Technologies Used

- **Programming Language:** Java
- **Database:** MySQL

## Project Modules

1. Donor Management
2. Recipient and Blood Request Management
3. Donation Record Management

## Installation and Setup
